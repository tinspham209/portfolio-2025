# Tin Pham's portfolio

[https://tinspham.dev/](https://tinspham.dev/)

## Stack

- React
- Rsbuild
- Three.js
- GSAP

## Deployment

Pushing to `main` builds the site and deploys the `dist` directory to GitHub Pages
through `.github/workflows/deploy-pages.yml`.

See [the GitHub Pages migration runbook](./docs/github-pages-deployment.md) for
the reusable setup, DNS, HTTPS, verification, and cache-troubleshooting steps.
